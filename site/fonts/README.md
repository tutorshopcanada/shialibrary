# Fonts

Self-hosted so visitors never contact a third-party font server (no request leaves this site just to draw text).

- **Inter** (variable, weights 400 to 600) by Rasmus Andersson. SIL Open Font License 1.1. https://github.com/rsms/inter
- **Instrument Serif** (regular) by Rodrigo Fuenzalida and Jordan Egstad, published through Google Fonts. SIL Open Font License 1.1. https://github.com/Instrument/instrument-serif

Both are used under the SIL Open Font License 1.1 (https://openfontlicense.org). The files here are the `latin` and `latin-ext` subsets from Google Fonts. If a name or a transliteration letter ever shows in a fallback font, add the missing subset.
